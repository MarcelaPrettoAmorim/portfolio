Projetos de Ciência de Dados

Dashboard operacional para marketplace de entregas

Painel interativo construído sobre dados de uma operação fictícia de delivery na Índia, com foco em monitoramento de KPIs operacionais (entregadores, restaurantes e pedidos). O projeto cobre o pipeline completo, do tratamento dos dados ao deploy em produção via Streamlit Cloud.

Tecnologias: Python, Pandas, Plotly, Streamlit, Streamlit Cloud e GitHub.

  • GitHub
  • Streamlit

Previsão de vendas para rede de farmácias Rossmann

Sistema de previsão de faturamento das próximas 6 semanas para qualquer loja da rede, voltado a apoiar decisões de planejamento estratégico. Após comparar Linear Regression, Lasso, Random Forest e XGBoost via cross-validation, escolhi XGBoost pelo equilíbrio entre desempenho e custo computacional. Random Search para tuning levou a uma melhoria expressiva: acurácia de 74,97% para 86,28% (MAPE 13,72%), com erro médio caindo de R$ 1.685 para R$ 955 por previsão. O modelo foi exposto via API Flask e consumido por um app Streamlit que permite consultar a previsão por loja.

Tecnologias: Python, Pandas, Scikit-Learn, XGBoost, Random Search, Flask, Streamlit, Streamlit Cloud e GitHub.

  • GitHub
  • Streamlit

Nem todo problema precisa de Machine Learning: análise para loja de jogos

Projeto pessoal motivado por um problema real: ajudar um amigo a compor o estoque inicial de uma loja de jogos de tabuleiro. Construí uma proxy de demanda (demanda_score) a partir de features do dataset, fiz análise exploratória pra entender o que influencia a procura, e gerei uma recomendação de 20 jogos prioritários para o estoque inicial. Avaliei a viabilidade de Machine Learning e concluí que o problema não exigia ML — uma análise estatística direta entregava mais valor com menos complexidade. Artigo completo no Medium.

Tecnologias: Python, NumPy, Pandas e Scikit-Learn.

Sobre mim

Engenheira de Produção formada pela UNIVEM, com cinco anos e meio de carreira na indústria alimentícia. Atuei na estruturação do processo produtivo de uma nova fábrica e no planejamento de demanda e suprimentos, sempre olhando para os dados antes de decidir.

Em 2023, percebi que aquilo que eu já fazia há anos tinha um nome formal: Ciência de Dados. O que descobri foi um campo inteiro dedicado a fazer isso com rigor, usando modelagem estatística e Machine Learning como ferramentas centrais. A partir daí, a transição virou um plano consciente: estudar a fundo, construir projetos próprios e migrar de carreira.

Curso o Bacharelado em Ciência de Dados pela Univesp, com previsão de conclusão em 2028, complementando com certificações específicas como Machine Learning Specialization (Coursera) e DP-100 Microsoft Azure Data Scientist. Mantenho projetos próprios end-to-end usando dados públicos, escrevo no Medium sobre o que aprendo e busco aplicar Ciência de Dados onde ela gera mais valor, inclusive sabendo reconhecer quando ela não é a resposta certa para o problema.
